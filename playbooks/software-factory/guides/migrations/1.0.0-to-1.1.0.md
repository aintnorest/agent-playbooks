# Migrate consumer repositories from 1.0.0 to 1.1.0

## Contract changes

- The review-round gate ends a document's blind full-review phase in one more case. A full round decided with no accepted Blocker/Major still settles the document; now, from the document's seventh full round on, a decided full round with no accepted Blocker also settles it, even when it accepted Majors. The next round is a change check of the diff and the accepted fixes, so those Majors are still verified before `review_ledger close` can succeed. Accepted Blockers keep full reviews going. The [review loop](../document-review.md#review-loop) owns the rule.

Ledger files, tool arguments, and `review_ledger status` fields are unchanged.

## Migration steps

1. **Upgrade the pin.** Change `version` to `1.1.0` in the consumer repository's `mise.toml`, run `mise install`, and start a fresh OMP session so the main session loads the updated `orchestrate-factory` skill.
2. **Expect existing ledgers to switch.** No ledger edit is needed. A document whose ledger already has seven or more full rounds, one of them from the seventh on decided with no accepted Blocker, receives a change check on its next review dispatch instead of another full review. Its open Major findings remain open blocking work until that change check is recorded and decided.
